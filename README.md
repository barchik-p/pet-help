# Pet Help

Uma plataforma para facilitar o contato entre doadores, ONG's e animais que precisam de ajuda!

---

## Sobre o Projeto
Muitas ONGs enfrentam dificuldades para divulgar animais disponíveis e gerenciar pedidos de adoção e doações de forma centralizada. O **Pet Help** resolve esse problema oferecendo um ecossistema simples e funcional tanto para os protetores quanto para os futuros tutores.

Este projeto foi desenvolvido e testado em ambiente local como parte dos meus estudos em desenvolvimento de software na matéria de **Desenvolvimento Web**, permitindo validar regras de negócio complexas como controle de permissões de usuários e gerenciamento de estados de pedidos.


## Funcionalidades

###  Módulo da ONG
- **Cadastro e Perfil da ONG:** Criação e gestão do perfil da instituição.
- **Gestão de Anúncios de Pets:** Publicação de animais disponíveis para adoção e remoção dos anúncios assim que a adoção for concluída.
- **Gerenciamento de Pedidos:** Análise de solicitações de adoção recebidas, com opção de aprovar/aceitar ou recusar/deletar o pedido.

###  Módulo do Usuário (Adotante / Doador)
- **Cadastro e Perfil do Usuário:** Criação de perfil pessoal na plataforma.
- **Fluxo de Adoção:** Envio de solicitações formais de adoção diretamente para a ONG responsável pelo animal.
- **Doações Diretas:** Funcionalidade para realizar doações financeiras ou de recursos para ONGs específicas.

## Tecnologias Utilizadas
- **Front-end:** HTML5, CSS3, JavaScript
- **Back-end:** PHP
- **Banco de Dados & Formato de Dados:** MySQL e JSON
- **Ambiente de Desenvolvimento:** VS Code, XAMPP / Localhost

## Aprendizados
Durante o desenvolvimento deste projeto, aprendi a:
- Modelagem e diferenciação de níveis de acesso (Perfis de ONG vs. Perfis de Usuário Comum).
- Estruturação de fluxo de aprovação (Criação, aceite e deleção de solicitações de adoção).
- Testes e validação da aplicação em ambiente local.
